SHAARAWY TECH — Website

النشر على GitHub Pages:
1) ارفع كل الملفات والمجلدات الموجودة هنا إلى مستودع GitHub جديد باسم shaarawy-tech.
2) تأكد أن index.html موجود في جذر المستودع (وليس داخل مجلد إضافي).
3) افتح Settings ثم Pages.
4) من Build and deployment اختر Deploy from a branch.
5) اختر Branch: main و Folder: /(root)، ثم Save.
6) انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

ملاحظات:
- رقم واتساب مضبوط على الرقم الذي أرسلته بصيغة مصر الدولية.
- ملف اللوجو موجود في assets/logo.png.
- النموذج يفتح واتساب برسالة جاهزة ولا يخزن البيانات في قاعدة بيانات.
- بطاقات الأعمال الحالية نماذج عرض؛ استبدلها بمشاريع وروابط حقيقية قبل التسويق.
- الموقع عربي/إنجليزي ومتجاوب مع الموبايل والكمبيوتر.
